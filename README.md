## 🎯 Objetivo General

Practicar la estructura básica de HTML5 mediante la creación de una página personal que presenta información sobre el estudiante, sus intereses y pasatiempos, además de enlaces a sus sitios favoritos.

---

## 📚 Contenidos Abordados

En este proyecto se utilizaron los siguientes elementos y conceptos de HTML5:

1. **Estructura básica de un documento HTML:**
   - `<!DOCTYPE html>`: declaración del tipo de documento HTML5.
   - `<html lang="es">`: elemento raíz e idioma del documento.
   - `<head>`: contiene metadatos, el título de la página y el enlace a la hoja de estilos.
   - `<body>`: contiene el contenido visible de la página.

2. **Títulos y texto:**
   - `<h1>`: muestra el nombre del estudiante como título principal.
   - `<h2>`: organiza las secciones de intereses y sitios favoritos.
   - `<p>`: presenta información personal, académica y profesional.

3. **Listas no ordenadas:**
   - `<ul>`: agrupa los intereses y pasatiempos, y los sitios favoritos.
   - `<li>`: representa cada elemento de las listas.

4. **Imagen e hipervínculos:**
   - `<img>`: inserta una imagen personal mediante el atributo `src` y proporciona una descripción con `alt`.
   - `<a>`: crea enlaces a sitios externos como Spotify, Discord y Steam.

5. **Hoja de estilos externa:**
   - `<link>` conecta el documento HTML con `Design.css` para aplicar estilos.
